# 🎓 C Learning Assistant - مساعد تعليم لغة C

تطبيق شامل لتعليم لغة C من الصفر حتى الاحتراف مع أمثلة عملية وتمارين تفاعلية!

## ✨ المميزات

- 📝 **محرر أكواد** - اكتب كود C مباشرة
- ⚙️ **محرر ومترجم** - شغّل برنامجك فوراً
- 📚 **دروس شاملة** - شرح كل المفاهيم من الأساس
- 💡 **أمثلة عملية** - أمثلة حية لكل موضوع
- 🎯 **تمارين** - مارس ما تعلمته
- ⚠️ **أخطاء شائعة** - تجنب الأخطاء من البداية
- 🔧 **أدوات مساعدة** - أدوات لفهم البرامج

## 🚀 كيفية الاستخدام

### التثبيت
```bash
git clone https://github.com/ywsfmalkhsynb-star/C-Learning-Assistant.git
cd C-Learning-Assistant
npm install
```

### التشغيل
```bash
npm start
```

## 📚 المحتوى التعليمي

### المستوى الأول: الأساسيات
- مقدمة عن C
- المتغيرات والأنواع
- العمليات الحسابية
- الإدخال والإخراج

### المستوى الثاني: التحكم
- الجملة الشرطية (if, else)
- حلقات التكرار (for, while, do-while)
- switch و break و continue

### المستوى الثالث: البيانات
- المصفوفات (Arrays)
- السلاسل النصية (Strings)
- البنى (Structures)

### المستوى الرابع: المؤشرات
- مقدمة المؤشرات
- العمليات على المؤشرات
- المؤشرات والمصفوفات
- المؤشرات والسلاسل

### المستوى الخامس: الدوال
- تعريف الدوال
- معاملات الدوال
- القيمة المرجعة
- Recursion (التكرار الذاتي)

### المستوى السادس: الملفات والذاكرة
- التعامل مع الملفات
- تخصيص الذاكرة (malloc, calloc)
- تحرير الذاكرة (free)
